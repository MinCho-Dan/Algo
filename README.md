# 📝 Algorithm Problem Solving (PS)

[![GitHub](https://img.shields.io/badge/GitHub-mincho--dan-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/mincho-dan)

알고리즘 실력 향상을 위해 꾸준히 문제를 풀고 기록하는 저장소입니다.  
문제를 풀며 배운 전략과 효율적인 코드 작성법을 정리합니다.

---

## 🛠️ 개발 환경 및 언어
* **Main Language:** ![Java](https://img.shields.io/badge/Java-007396?style=flat-square&logo=Java&logoColor=white) ![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat-square&logo=Kotlin&logoColor=white)
* **IDE:** IntelliJ IDEA / Visual Studio Code / Eclipse
* **Platforms:** Baekjoon(서비스종료), SWEA, 프로그래머스

---

## 📁 폴더 구조
문제의 출처와 유형별로 분류하여 관리합니다.

```
.
├── src/                        # 26년도 BOJ 서비스 종료 이전까지 풀었던 문제들을 수동으로 업로드하던 폴더
│   ├── Baekjoon/               # 백준 온라인 저지 (Solved.ac 티어별 분류)
│   │   ├── Gold/
│   │   ├── Silver/
│   │   └── Bronze/
│   ├── SWEA/                   # SW Expert Academy (난이도별 분류)
│   ├── AlgorithmUnderstand/    # 알고리즘 개념 공부용 기본 구현 코드
│   └── _Practice/              # 💡 문제 풀이 및 테스트를 위한 연습 공간
├── 프로그래머스                   # 프로그래머스 문제 풀이 ${platform}/${level}/${id}. ${title} 형태로 정리.
├── .gitignore                  # 불필요한 설정 파일(bin, .project 등) 제외
└── README.md                   # 프로젝트 가이드 및 문제 풀이 현황
```
